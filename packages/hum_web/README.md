# hum_web
## Web Audio (AudioWorklet) I/O bridge for Hum

This package lets you run [hum](https://pub.dev/packages/hum) pipelines on the web.  

Tested in Firefox and Chrome. I'd expect it to work fine in other modern browsers, feel free to file an issue if not.  

I'll improve this readme later but for now, look at the example for usage.
